# 转换示例

以下案例用于学习转换方法。处理真实任务时保留用户主体和创意，不复用这里的场景、人物或台词。

## 示例 1：单人物情绪镜头

### 2.0 风格输入

```text
一个美丽优雅的女人穿华丽红裙缓缓走来，史诗级电影感，赛博朋克，胶片质感，手持环绕推进，8K，不要模糊不要变形。
```

### 2.5 重构

```text
一名 25 岁女性，黑色齐肩发，穿酒红色丝绒长裙，从酒店大厅远端走向镜头，在距镜头两米处停下并轻轻侧头。夜晚的古典大厅，暖色吊灯从左前方照亮面部，大理石地面有柔和反光。暖色电影影调，细颗粒，浅景深。

0–5 秒：中景固定构图，人物从远端开始走近。
5–11 秒：镜头缓慢推进，人物继续走近并停下。
11–15 秒：胸像近景，人物轻轻侧头，保持稳定收尾。

<鞋跟脚步声，远处低语> (稀疏弦乐)

[保持一致] 人物五官、发型、长裙颜色和款式全程一致；只出现一名人物；主体眼睛清晰对焦。
```

## 示例 2：女装电商带货

### 2.0 风格输入

```text
年轻中国女生全身试穿，转身展示版型，手摸面料，拉衣摆，展示领口袖口，显瘦垂感，抖音带货风，背景不要杂乱，自然口播。
```

### 2.5 重构

```text
一名 20 岁出头中国女性，黑色长直发，自然淡妆，穿[需补充：服装款式和颜色]，站在浅色墙面的简洁直播间，身后只有一组虚化衣架。正面偏左的柔和灯光照亮人物和服装，手机拍摄质感。

0–3 秒：全身固定中景，人物微笑打招呼。
3–7 秒：人物自然转身一周，面料随动作自然下坠摆动，镜头切到半身跟拍。
7–11 秒：人物回到正面，右手触摸面料，左手轻拉衣摆，展示宽松度。
11–15 秒：近景展示领口和袖口，最后回到半身中景点头收尾。

对白语言：中文，年轻女声，亲切自然，语速偏快。
{[需补充：15 秒内的实际口播台词]}
<轻微脚步声，面料摩擦声>

[保持一致] 人物和服装全程一致；人物动态出镜；背景保持简洁；最后停在稳定画面。
```

## 示例 3：产品广告与参考图

### 2.0 风格输入

```text
参考图里的香水瓶，高级奢华广告，水面、花瓣、烟雾、旋转、推进、环绕，瓶身不要变形，logo 要清楚。
```

### 2.5 重构

```text
@image1 定义香水瓶的几何形状、玻璃材质、液体颜色和标签位置，不使用其背景、桌面和光线。

透明香水瓶立在黑色镜面台上，瓶后有一束窄幅暖光，玻璃边缘形成柔和轮廓光。少量水雾贴近台面缓慢流动，画面只保留产品和一片浅色花瓣。

0–5 秒：固定近景，香水瓶保持静止，水雾从右向左流动。
5–11 秒：镜头缓慢环绕四分之一圈，产品始终位于画面中心。
11–15 秒：镜头停止，标签正面朝向镜头，稳定收尾。

<一滴水落在镜面上的声音> (低频、稀疏的氛围音乐)

[保持一致] 瓶体比例、瓶盖形状、液体颜色和标签位置全程不变。精确品牌文字在后期叠加。
```

## 示例 4：双人对白

### 2.0 风格输入

```text
雨夜两个人争吵然后和解，有电影感，镜头推拉摇移，对白自然，要字幕。
```

### 2.5 重构

```text
雨夜公交站，一名穿深蓝外套的短发女性与一名穿灰色夹克的男性相隔一米面对面站立。站牌顶灯从上方照亮雨丝，背景车流虚化，冷蓝色调。

0–6 秒：固定双人中景，女性压低声音说话，男性沉默看向地面。
对白语言：中文，女声克制而急促。
{你为什么现在才来？}
【你为什么现在才来？】

6–12 秒：切到男性近景，他抬眼回答，语速缓慢。
对白语言：中文，男声低沉、疲惫。
{我一直都在，只是不敢过来。}
【我一直都在，只是不敢过来。】

12–18 秒：回到固定双人中景，两人停止争执并并肩看向雨幕，保持稳定。
<雨打站牌，远处车辆驶过>

[保持一致] 两人的五官、服装、站位关系和雨势全程一致。
```

## 示例 5：仙侠多镜头动作

### 2.0 风格输入

```text
ARRI、柯达胶片、IMAX、16:9、极致细节。女魔神飞过战场，指天开阵，快速结六个手印，万雷落下，法相拔地拍出五层冲击波，手持、推进、拉远、固定俯拍，能量不要硬边不要刺眼。
```

### 2.5 重构要点

- 删除器材型号与冲突画幅，把它们翻译为冷青蓝紫影调、柔和高光、暗部层次和细颗粒。
- 将参考人物与结印动作分别绑定到 `@image1`、`@image2`，同时排除背景和服装污染。
- 按出场、开阵、结印、闪白、雷击、法相、拍地分段；不同镜头允许不同运镜。
- 六个手印若必须清晰，延长结印段或减少手势数量。
- 把“不要硬边、不要刺眼”改为“半透明、低亮度、边缘虚化的云雾气态能量”。
- 用 `[保持一致]` 锁定人物外观、服装、悬浮状态、主色调和穹顶延续时间。

此类高密度动作应先一次生成并检查关键段；若后半段漂移，拆成“人物出场与开阵”和“战场攻击与法相”两条视频后期剪辑。
