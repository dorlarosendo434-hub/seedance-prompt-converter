## 1. 语言具体化

把评价、气氛标签和设备型号转换为可观察的画面结果。

| 旧写法 | 可执行写法 |
|---|---|
| 美丽、优雅 | 具体年龄、发型、服装、表情、姿态 |
| 史诗级、大片感 | 超大全景、主体尺度对比、深层空间、低频声场 |
| 电影感 | 焦段、景别、光源方向、色温、景深、颗粒和镜头速度 |
| ARRI、柯达胶片 | 柔和高光、保留暗部层次、暖肤色、细颗粒 |
| 8K、超高清 | 删除；清晰度由生成参数控制 |
| 显瘦、垂感 | 侧身展示腰线；面料随转身自然下坠摆动 |

优先使用具体名词和可见动词。保留真正影响内容的材质、颜色、形状和空间关系。

## 2. 冲突消解

同一镜头中只保留一个主选择：

- 风格：写一个主风格；删除互斥媒介或解释主次关系。
- 运镜：固定、推进、拉远、环绕、手持、横移中选一种主运镜。
- 场景：不要保留“直播间或服装店”之类未决选项。
- 动作：一个时间窗口只放一个核心变化。

不同分镜允许使用不同运镜。判断冲突时先按时间段切分，不做全局机械判定。

## 3. 约束正向化

负面约束要短、可检查；能通过正面画面描述解决时优先正向表达。

| 负面写法 | 推荐写法 |
|---|---|
| 不要背景杂乱 | 浅色墙面，背景虚化，只保留一组货架 |
| 不要欧美模特 | 中国女性面孔 |
| 不要夸张妆容 | 自然淡妆 |
| 不要静物摆拍、不要没人 | 人物全程动态出镜 |
| 不要模糊 | 主体眼睛与产品边缘清晰对焦 |
| 不要多余运镜 | 全程固定机位，人物停下后保持稳定 |

仍可保留少量必要的排除项，例如“不出现品牌、画面文字或额外人物”。不要堆成长串负面词。

## 4. 时间线重组

每段采用“承接状态 → 一个核心变化 → 结束状态”。

推荐 30 秒结构：

- 0–5 秒：建立主体和吸引点
- 5–16 秒：展开主要动作或问题
- 16–25 秒：展示结果、证据或转折
- 25–30 秒：稳定收束和呼应

15 秒短视频可压缩为 3–5 段。动作多时优先延长时长或拆成多条生成，不要把所有动作强塞进同一时间段。

## 5. 参考素材绑定

按上传顺序使用 `@image1`、`@video1`、`@audio1`。每份素材都要说明职责和排除项：

```text
@image1 定义人物五官、发型和肤色，不使用其服装、背景和光线。
@image2 定义产品形状、材质和标签位置，不使用其拍摄角度和桌面道具。
@video1 定义动作节奏和镜头路径，不使用其中的人物身份与场景。
```

一项关键属性只设一份主参考。参考素材多不等于更稳定；删除职责重叠或相互矛盾的素材。

## 6. 声音路由

| 语法 | 用途 | 示例 |
|---|---|---|
| `( )` | 音乐或环境床 | `(稀疏钢琴与低频环境氛围)` |
| `< >` | 物理音效 | `<鞋跟脚步声，雨打玻璃>` |
| `{ }` | 角色对白 | `{我们该走了。}` |
| `【 】` | 画面字幕 | `【我们该走了。】` |

对白语言、音色、语气和语速写在花括号外；花括号内只放台词。对白与字幕是独立通道，需要两者时分别写一遍。每段声音控制在 2–3 个明确元素。

## 7. 一致性锁定

用 `[保持一致]` 只锁定真正不能漂移的项目：

- 人物五官、发型、肤色、服装颜色与款式
- 产品几何形状、材质与标签位置
- 道具由谁持有、角色数量和站位关系
- 光线方向、主色调和关键场景结构
- 需要跨镜头延续的能量、天气或环境状态

不要把普通画面描述全部重复进约束块。

## 8. 常见映射与检查表

### 镜头词

| 目标 | 写法 |
|---|---|
| 强调人物或产品 | 缓慢推进，从中景到近景 |
| 揭示环境 | 缓慢拉远，从近景到大全景 |
| 展示侧面结构 | 横向跟移，速度与主体一致 |
| 展示全貌 | 缓慢环绕，保持主体在画面中心 |
| 纪实感 | 轻微手持跟拍，不叠加环绕或摇臂 |
| 稳定展示 | 固定机位，不切换角度 |

### 提交前检查

- 主体和主要动作用平实语言写清了吗？
- 每份参考素材是否同时写了使用项和排除项？
- 每段是否只有一个主要变化和明确结束状态？
- 是否只设一种主运镜，或明确了切换顺序？
- 光源方向、色温和材质是否具体？
- 对白、字幕、音效和音乐是否分通道？
- 负面约束是否简短且可逐帧检查？
- 人物、产品、道具和空间关系是否被必要地锁定？
- 最后一段是否留出稳定画面？
- 精确文字和 Logo 是否计划后期添加？
